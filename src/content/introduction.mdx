## About JSONPlaceholder

JSONPlaceholder is a public fake REST API for testing and prototyping. It provides sample resources such as posts, comments, albums, photos, todos, and users.

The examples in this documentation use the /posts resource to demonstrate HTTP requests and response validation without requiring an API key.

<Note type="info" title="Test API only">
  JSONPlaceholder is intended for testing and prototyping. Do not use it to store production data or rely on it as a production backend.
</Note>
