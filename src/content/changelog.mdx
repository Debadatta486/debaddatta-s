## v0.1.0

Initial release of the documentation site.

- **Introduction and quickstart** covering project setup and first steps. See the [introduction](/introduction) and [quickstart](/quickstart) pages.
- **Browsable API reference** generated from `openapi.yaml`, with an interactive playground for trying requests. Start at [API introduction](/api/introduction).
- **Agent discovery endpoints** such as `/llms.txt`, `/.well-known/mcp.json`, and `/.well-known/agent-card.json` so LLM-based tools can find and read the docs programmatically.
- **Read-only MCP endpoint** at `/api/mcp` exposing tools like `search_docs`, `read_page`, `list_pages`, and `get_api_operation`.
